# Стили сайта

`site.css` — основной статический файл стилей, подключённый в `index.html`.
Секции подписаны именами компонентов и прежних источников; порядок секций
сохраняет существующий каскад, темы и мобильные правила.

При переносе относительные URL пересчитаны относительно каталога `assets`.
Изображения, шрифт и их содержимое не менялись. Удалены подтверждённые повторы
правил фоновых изображений и отступа блока рублёвых размещений.

Прежние CSS-файлы сохранены для истории и совместимости, но `index.html` их
отдельно не подключает. Изменения текущего оформления следует вносить в
соответствующую секцию `site.css`, затем обновлять версию ссылки в HTML.
Отдельная сборка стилей не требуется.

Стили компонентов, создаваемые JavaScript во время работы страницы, этим
переносом не затронуты. До упрощения перекрывающихся правил проверяйте обе
темы, мобильные размеры и все затрагиваемые разделы.
