# Сравнение фондов и калькулятор доходности

Готовая статическая сборка для GitHub и Netlify. Сервер и база данных не требуются.

## Что находится в папке

- `index.html` — сайт, калькуляторы и Яндекс.Метрика;
- `assets/` — шрифт, изображения фондов и продуктов;
- `rates.json` — ставки и доступные сроки Т‑Счёта и Инвестзайма;
- `funds.json` — обновляемые биржевые показатели фондов;
- `market-rates.json` — актуальное значение RUSFAR;
- `spk-config.json` — комиссии СПК 2.0 по клиентским сегментам;
- `model-portfolios.json` — пропорции классов активов для страницы «Модельный портфель»;
- `model-recommendations.json` — фонды и сохранённые рекомендации аналитиков по классам активов;
- `assets/smart-sales.css` и `scripts/smart-sales.js` — меню «Умные продажи» и калькулятор модельного портфеля;
- `scripts/update-data.mjs` — ежедневное получение данных с MOEX ISS;
- `.github/workflows/update-data.yml` — автоматический запуск в 13:15 МСК.

## Первая загрузка в GitHub

1. Откройте репозиторий `funds-calculator`.
2. Нажмите **Add file → Upload files**.
3. Перетащите **содержимое** этой папки, включая `.github`, `assets`, `scripts` и файлы из корня.
4. В поле сообщения напишите, например, `Добавлен СПК и ежедневное обновление`.
5. Нажмите **Commit changes**.

Важно: папки `.github`, `assets` и `scripts` должны находиться рядом с `index.html` в корне репозитория.

## Проверка автоматического обновления

1. В GitHub откройте вкладку **Actions**.
2. Слева выберите **Daily funds and RUSFAR update**.
3. Нажмите **Run workflow → Run workflow**.
4. После успешного запуска в истории репозитория появится коммит `Daily funds and RUSFAR update`, если данные изменились.
5. Откройте `market-rates.json` и проверьте поля `value`, `valueDate` и `updatedAt`.

Расписание: ежедневно в `10:15 UTC`, то есть в `13:15 МСК`. Мосбиржа рассчитывает основное значение RUSFAR около 12:30 МСК, поэтому запуск в 13:15 обычно получает значение текущего торгового дня. В выходной или при отсутствии нового расчёта дата `valueDate` может остаться прежней.

## Netlify

Если Netlify уже подключён к GitHub, дополнительная загрузка не нужна: новый коммит автоматически запускает deploy. В **Deploys** должен появиться новый успешный деплой.

Если Netlify ещё не подключён:

1. В Netlify выберите **Add new project → Import an existing project**.
2. Подключите GitHub и выберите `funds-calculator`.
3. Build command оставьте пустым.
4. Publish directory укажите `.`.
5. Нажмите **Deploy**.

## Как обновляются данные

- RUSFAR берётся из официального MOEX ISS и записывается в `market-rates.json`.
- Сайт запрашивает `market-rates.json` без браузерного кэша при открытии страницы СПК и повторяет запрос каждую минуту, пока страница открыта.
- После изменения JSON перепубликовывать `index.html` не нужно.
- Рыночные цены и доступная история фондов обновляются тем же workflow в `funds.json`.
- Комиссии СПК 2.0 загружаются из `spk-config.json`: MM 5%, PRO 4%, Bronze/Silver 3%, Gold 2%, Diamond/Private 1%, сотрудники Т 0%.
- Расходы фонда `0,25% в год` показываются справочно и дополнительно в калькуляторе не вычитаются.

## Ручное изменение ставок Т‑Счёта и Инвестзайма

Отредактируйте `rates.json`. Числа записываются через точку, например `14.7`. После коммита сайт получит новые значения. Выпадающий список показывает только сроки, которые присутствуют в JSON.

## Умные продажи и модельные портфели

В верхнем меню находится раздел «Умные продажи». При наведении или нажатии открывается пункт «Модельный портфель».

В `model-portfolios.json` записаны официальные консервативный, сбалансированный и портфель роста из летнего обновления стратегии Т‑Инвестиций 2026 года. Умеренно-консервативный и умеренно-агрессивный профили рассчитаны как среднее между соседними официальными портфелями и помечены как интерполяция. Сумма значений в объекте `assets` каждого профиля должна составлять ровно 100.

`model-recommendations.json` содержит подходящие фонды Т‑Капитала и подтверждённые на 07.10.2026 рекомендации из предоставленных материалов. Если рекомендаций для класса нет, сайт показывает отсутствие сохранённых данных и не подставляет нулевые или вымышленные значения.

## Формула СПК

1. Доходность для расчёта = `RUSFAR − встроенная комиссия сегмента`.
2. Начисление СПК капитализируется ежедневно.
3. Комиссия отдельно в рублях не списывается и в результате не показывается.
4. При включённом НДФЛ калькулятор применяет 13% к рассчитанному доходу СПК и вклада.

Калькулятор носит расчётный характер. Перед использованием в клиентской коммуникации формулировки и налоговую методику следует согласовать с ответственным подразделением.
