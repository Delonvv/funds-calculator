# Каталог фондов — версия 3

Независимый статический каталог. Для публикации не требуется сборка, `index.html` находится в корне. Для локального просмотра нужен HTTP-сервер, чтобы браузер мог читать JSON-файлы.

Сохранены исходный шрифт и жёлтая палитра, фоны без юлы, щит НСЖ, финансовые модели и конфигурационные JSON-файлы.

## Изображения

`assets/fund-illustrations-v2.png` — оригинальный набор золотистых иллюстраций 6×6, без фирменных знаков фондов. Привязка к тикерам задана в `fundIllustrations` в `index.html`. Стили спрайта и карточек находятся в `assets/publication.css`.

`assets/issuers/` — шесть изображений эмитентов из источника текущих размещений. Скрипт обновления сохраняет локальные пути для известных эмитентов и внешнюю ссылку для новых; при недоступности изображения остаётся текстовый знак эмитента. Логотип банка в общей шапке не используется.

## Нижнее напоминание

Общий блок `.site-independence` расположен вне `main`, после его закрывающего тега. Поэтому динамически создаваемые страницы НСЖ и «Умных продаж» всегда находятся перед ним. Напоминание видно внизу каждого раздела, включая СПК.

## Обновление данных

Существующий workflow `.github/workflows/update-funds.yml` сохранён. Инструкция локального обновления — `README-MAC-UPDATER.md`. Финансовые условия и налоговые модели не пересматривались.

## Замена

Содержимое этой папки переносится в корень прежнего репозитория. Если установлена первая полная версия `site-release`, достаточно загрузить все файлы с заменой, включая новые изображения. При переходе с первоначальной брендированной версии старые ресурсы, отсутствующие здесь, нужно удалить; каталог `.git` сохраняется.

## Фоны — версия 3

На фондах и «Миссии» используются отдельные элементы изображений `assets/funds-background-v3.png` и `assets/mission-background-v3.png`. В обоих изображениях юла удалена, остальной фон сохранён. Старые псевдоэлементы фона отключены; названия файлов и версии CSS обновлены.
