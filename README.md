# Каталог фондов

Независимый статический каталог и калькуляторы. Для размещения не требуется сборка: файл `index.html` находится в корне.

Сохранены исходный шрифт, жёлтая палитра, финансовые модели и конфигурационные JSON-файлы. На главной странице и странице «Миссия» убрана юла, в НСЖ используется золотой щит. Логотипы фондов и банковская идентичность проекта удалены, включая прежний значок вкладки и альтернативную страницу.

## Локальный просмотр

Откройте папку через любой локальный HTTP-сервер (например, `python3 -m http.server 8000`) и перейдите на `http://localhost:8000`. Открытие двойным щелчком через `file://` может блокировать загрузку JSON в браузере.

## Обновление данных

Существующий ежедневный GitHub Actions workflow сохранён в `.github/workflows/update-funds.yml`. Скрипты читают котировки и условия из прежних источников. Сборщик размещений сохраняет текстовые сведения без логотипов; интерфейс также игнорирует изображения эмитентов.

Настройка локального обновления: `README-MAC-UPDATER.md`. Не запускайте установщики или обновления для простой публикации сохранённых файлов.

## Публикация

Замените файлы существующего сайта содержимым этой папки. Каталоги `assets` и `scripts` заменяются целиком. Устаревшие логотипы и фоновые файлы должны быть удалены из репозитория, а не оставлены рядом с новой версией. Папку `.git` сохраняйте.

Финансовые условия и налоговые модели не пересматривались. Сохранение внешних источников необходимо для идентификации инструментов и не означает аффилированности проекта с их владельцами.
