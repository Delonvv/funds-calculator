# Обновление данных при входе в раздел

`scripts/page-data-refresh.js` регистрирует адаптеры существующих источников.
После завершения `showProductPage` проверяется только конечный раздел, включая
переходы из меню, подбора и ссылки с hash. Полной перезагрузки документа нет.
Нет фонового таймера и обновления расчёта посреди разговора: проверка происходит
при переходе или повторном нажатии вкладки.

| Раздел | Источник |
|---|---|
| Фонды | funds.json, dcm.json, rates.json, rentier-config.json, investloan-monthly-rates.json |
| Т‑Счёт | rates.json |
| Инвестзайм | rates.json, investloan-monthly-rates.json |
| СПК | spk-config.json, market-rates.json |
| НСЖ / Рантье | nszh-config.json, rentier-config.json |
| ПДС | pds-config.json |
| Модельный портфель | model-portfolios.json, model-recommendations.json |
| Стратегия | strategy-2026.json |
| Премиум банков | premium/data.js — только JSON из присваивания, без исполнения загруженного JS |
| Fixed Income / валютные размещения | dcm.json |

Сохранены сумма, доступный выбранный срок, режим выплат, параметры вклада,
параметры ПДС, профиль модели, ступень и выбранные банки, поиск, фильтры,
избранное и выбор продукта в подборе. При исчезновении выбранного срока из новых
условий выбирается доступный срок; менеджер видит сообщение об обновлении и
должен сверить ставку в расчёте. Ручная сценарная ставка продукта при его повторном
открытии заменяется опубликованной ставкой выбранного срока; предположения по
вкладу не сбрасываются. Открытый общий калькулятор фондов не пересчитывается.

Запросы `no-store`, ограничение 12 секунд. Один файл запрашивается один раз на
переход даже при нескольких потребителях. Новый переход делает новый запрос;
запоздалый ответ предыдущего перехода не заменяет свежий результат. Если снимок
не изменился, повторной отрисовки нет. Ошибка HTTP/JSON/проверки структуры
не заменяет предыдущие значения; появляется сообщение о частично недоступных
источниках. Обновление разных независимых источников может быть частичным.

Отдельно запрашивается текущий index.html. Статическая справка уровней Сбера
обновляется из одноимённой секции. Изменение состава скриптов, версий ресурсов
или встроенного кода показывает кнопку «Обновить интерфейс»; принудительной
перезагрузки и выполнения скачанного JavaScript нет. Изменения шаблонов,
встроенного каталога, дизайна и программной логики требуют этой кнопки — нельзя
выдавать обновление JSON за безопасную замену работающего приложения. При
релизах JS/CSS следует менять версии соответствующих ссылок в index.html.

Сначала выполняется обычная начальная загрузка. Уже открытые до внедрения этого
механизма вкладки нужно один раз обновить: старый код не может сам получить
функцию, которой в нём ещё нет.

Регрессионные проверки `checks/refresh.mjs`: изменяемые ответы источников в той же
вкладке, перенос срока из подбора, ставки, СЧА, НСЖ/Рантье, ПДС, СПК, модель,
стратегия, банки, размещения, восстановление после некорректного JSON и новая
версия интерфейса. Тестовые финансовые значения подменяются только в браузере;
рабочие JSON, финансовые правила, расписания обновления и Netlify не меняются.
