# Лента рублёвых размещений в каталоге

Компактная лента заменяет прежний двухслайдовый баннер. Фонды, их данные,
поиск и фильтры сохраняются. Подбор выплат доступен текстовой кнопкой в панели
каталога, модельный портфель — через меню «Умные продажи».

Источник — существующий `dcm.json`. Лента использует тот же `placementList`, что
Fixed Income: валютный отбор, исключения и удаление дублей не дублируются.
Логотипы эмитентов берутся из `image`; при ошибке остаётся монограмма.
Новых запросов JSON при обычной загрузке каталога нет: используется уже существующая
загрузка размещений для подбора. Ставки, даты и расписание автообновления не меняются.
Купон выводится исходным текстом, неизвестные условия не заменяются нулями.
Рядом указано время исходного JSON по Москве; это дата файла, а не подтверждение
обновления каждой записи. За деталями карточки и ссылка ведут в Fixed Income.

Стрелки и клавиши влево/вправо при фокусе на ленте переключают размещения вручную;
на телефоне работает нативная горизонтальная прокрутка. Автопрокрутки нет.
`prefers-reduced-motion` отключает плавную прокрутку стрелками. Высота ленты
зарезервирована при загрузке, чтобы каталог не прыгал. При ошибке доступна повторная
загрузка; отсутствие размещений не скрывает фонды.

Иконка и название каждого фонда открывают `fundSource` в новой вкладке с
`noopener noreferrer`. Используется существующее сопоставление тикера, биржевого
обозначения и суффикса `@`, в том числе в горизонтальной ленте подбора.

Проверки: полный `node checks/run.mjs`, самопроверки `node checks/self-test.mjs`.
Браузерные сценарии проверяют совпадение с Fixed Income, стрелки, свайп, отсутствие
автопрокрутки, ошибку/повтор/пустой JSON, открытие брокерской карточки по названию
и иконке, подбор и сброс, сохранение избранного и обе темы на 360/390/768/1440 px.
