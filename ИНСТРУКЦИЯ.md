# Облегчённая версия сайта

В этой папке находится готовая версия сайта с вынесенными изображениями:

```text
funds-site-webp/
├── index.html
├── funds.json
├── rates.json
└── assets/
    ├── t-sans-regular.otf
    ├── hero-funds.webp
    ├── t-account.webp
    ├── investloan.webp
    └── fund-*.webp
```

`index.html` и папку `assets` нельзя разделять или переименовывать: HTML обращается к файлам по относительным путям `assets/...`.

## Что изменено

- 29 PNG-изображений вынесены из HTML и преобразованы в WebP.
- Шрифт T Sans вынесен в `assets/t-sans-regular.otf`.
- Все ссылки в `index.html` уже заменены на внешние файлы.
- `rates.json` и `funds.json` оставлены рядом с HTML, поэтому загрузка ставок и данных фондов работает по прежней схеме.
- Удалён служебный Netlify HUD, который был записан после закрывающего тега HTML.
- Логика сайта, калькуляторы и цели Яндекс Метрики не менялись.

## Как заменить файлы в GitHub

Важно: загружайте **всё содержимое** папки `funds-site-webp`, а не только новый `index.html`.

### Вариант 1 — через сайт GitHub

1. Распакуйте архив на компьютере.
2. Откройте репозиторий `funds-calculator`.
3. В корне репозитория нажмите **Add file → Upload files**.
4. Перетащите одновременно:
   - `index.html`;
   - `funds.json`;
   - `rates.json`;
   - всю папку `assets`.
5. Если GitHub не позволяет заменить существующие файлы одним действием, сначала откройте старый файл, нажмите значок корзины и подтвердите удаление. Папку `assets` достаточно добавить как новую.
6. В поле сообщения коммита напишите, например: `Optimize images and move assets to WebP`.
7. Нажмите **Commit changes**.
8. Проверьте структуру репозитория: рядом с `index.html` должны находиться `funds.json`, `rates.json` и папка `assets`.

### Вариант 2 — через Git на компьютере

Скопируйте содержимое распакованной папки в локальную папку репозитория с заменой, затем выполните:

```bash
git add index.html funds.json rates.json assets
git commit -m "Optimize images and move assets to WebP"
git push
```

## Как обновить Netlify

### Если Netlify связан с GitHub

После коммита Netlify сам запустит новый deploy. Откройте **Deploys** и дождитесь статуса **Published**. Вручную загружать файлы не нужно.

### Если используется ручная загрузка

1. Откройте страницу проекта Netlify.
2. Перейдите в **Deploys**.
3. Перетащите туда целиком распакованную папку `funds-site-webp`.
4. Дождитесь статуса **Published**.

Не загружайте только `index.html`: без папки `assets` картинки и шрифт не появятся.

## Проверка после публикации

1. Откройте сайт в режиме инкогнито.
2. Нажмите `Ctrl + Shift + R`, чтобы обойти старый кэш.
3. Проверьте главную картинку и значки нескольких фондов.
4. Откройте вкладки «Т‑Счёт» и «Инвестзайм» и проверьте их изображения.
5. Выберите срок: ставка должна подставиться из `rates.json`.
6. Откройте калькулятор фонда и убедитесь, что расчёт выполняется.

Если после обновления картинки не видны, почти всегда причина в том, что папка `assets` не попала в корень публикации. Адрес вида `https://ваш-сайт.netlify.app/assets/hero-funds.webp` должен открывать картинку напрямую.

## Как менять картинки дальше

Можно заменить любой файл в `assets`, сохранив его текущее имя. Тогда править HTML не потребуется. Желательно сохранять изображение в WebP и не менять пропорции.

Для добавления новой картинки:

1. положите её в `assets`;
2. укажите в HTML путь `assets/имя-файла.webp`;
3. закоммитьте оба изменения.

## Работа автоматических данных

Разделение картинок на отдельные файлы не меняет автообновление:

- ставки продолжают загружаться из `rates.json`;
- данные фондов продолжают загружаться из `funds.json`;
- еженедельный скрипт может обновлять `funds.json`, не трогая `index.html` и `assets`.
