# Еженедельное обновление данных фондов

## Какие файлы загрузить в репозиторий

Сохраните структуру папок:

```text
index.html
rates.json
funds.json
scripts/update-funds.mjs
.github/workflows/update-funds.yml
```

На GitHub нажмите **Add file → Upload files** и перетащите папку комплекта целиком. Важно, чтобы файлы `update-funds.mjs` и `update-funds.yml` остались в указанных папках.

## Как работает расписание

Workflow запускается каждый понедельник в 09:15 по Москве. Он:

1. получает котировки и дневные свечи через MOEX ISS;
2. обновляет последнюю цену в `funds.json`;
3. рассчитывает изменение биржевой цены за 1, 6 и 12 месяцев;
4. не заменяет отсутствующие данные нулями;
5. сохраняет прежние данные при ошибке отдельного тикера;
6. делает commit в ветку `main`;
7. Netlify автоматически публикует новый `funds.json`.

TPAY исключён из автоматического расчёта доходности, потому что изменение цены не учитывает выплаты пайщикам. Для TGLD сохранена прежняя историческая доходность, чтобы не смешивать долларовую и рублёвую базу.

## Первый ручной запуск

1. Откройте репозиторий на GitHub.
2. Перейдите в **Actions**.
3. Слева выберите **Weekly fund data update**.
4. Нажмите **Run workflow**.
5. Выберите ветку `main` и подтвердите запуск.
6. Дождитесь зелёной галочки.
7. Проверьте, что у `funds.json` появился commit `Weekly fund data update`.
8. В Netlify дождитесь статуса **Published**.

## Если GitHub не может сделать commit

Откройте **Settings → Actions → General → Workflow permissions**, выберите **Read and write permissions** и сохраните. После этого повторите ручной запуск.

## Что не обновляется автоматически

Скрипт не изменяет расходы фонда, прогнозную доходность, СЧА, доступность квалам/неквалам, комиссии при выходе и санкционный статус. Эти сведения требуют проверки официальных документов и остаются сохранёнными в HTML/ручной части данных.

## Проверка на сайте

Откройте:

```text
https://ВАШ-САЙТ.netlify.app/funds.json
```

Проверьте поля `updatedAt`, `lastRun`, `market` и `failedTickers`. Массив `failedTickers` может содержать фонды, которых нет на биржевом рынке Мосбиржи; это не обнуляет их прежние показатели.
